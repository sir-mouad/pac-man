# Project management

This folder holds the team's planning and tracking documents for the Pac-Man project.

- requirements.md: the subject's requirements, with the status of each one [`requirements.md`](requirements.md)
- timeline.md: planned phases and what actually happened [`timeline.md`](timeline.md)
- progress.md: dated log of work sessions [`progress.md`](progress.md)
- decisions.md: key choices and the reasons for them [`decisions.md`](decisions.md)
- risks.md: known risks and how they are handled [`risks.md`](risks.md)
- blockers.md: problems that blocked progress, how they were solved, and what is still open [`blockers.md`](blockers.md)
- test-plan.md: what is checked, how, and what is still to do by hand [`test-plan.md`](test-plan.md)
- team.md: roles and how decisions are made [`team.md`](team.md)
